Hunt settings
Clues, in order

Each marker's clue is shown right after that marker is scanned, and should point to where the next marker is hidden. The last clue's marker triggers the win screen.

Printable markers

Print or screenshot these and place them physically at each stop. Each marker's QR code encodes that stop's code — scanning it is what checks the player in.
